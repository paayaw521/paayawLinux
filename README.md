# Remote Git Exercises
## 📌 Overview
This repository contains my solutions to the remote Git exercises provided in the assignment. The tasks involve setting up a remote repository, initializing a local Git repository, making structured commits, and organizing the solutions and image assets.
## 🛠️ Setup Instructions
To complete this exercise, the following steps were taken:
1. Created a **remote repository** on GitHub.
2. Initialized a **local repository**.
3. Added initial changes and committed them.
4. Changed the **default branch name** (previously `master`) to my name.
5. Structured the project with required folders and files:
   - `images/`: Contains all image assets.
   - `solutions.md`: Contains answers to the exercise questions.
   - `exercises.md`: Contains the exercise questions (if included).
